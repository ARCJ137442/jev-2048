发现不兼容的旧存档

本机存有一份旧数据，但当前版本读不懂它。
它可能是更早版本写下的，或者已被外部修改。
为避免丢掉你原本的进度，应用没有自动清理它 —— 请先决定如何处理。 

    


    

      强行加载会尽力从这份数据里抢救出可用的部分：
      棋盘与分数通常没问题，读不懂的字段会被丢弃并如实告知。

      建议顺序：先「导出旧数据」留底，再决定强行加载还是重置。
    


    

      
      
      
      
    

  







  

    
额度不足


    

      当前后端的调用额度已用尽或被限流。

      这通常不是网络问题，重试也不会恢复 —— 换个后端或用自己的 Key 即可继续。
    


    

      
      

    


    

      
      

        1. 切到 Vercel AI Gateway 直连，填自己的 API Key（推荐，额度归你掌控）

        2. 换用 TypeSafe 官方 或 OpenRouter 后端

        3. 稍后再试 —— 如果是共享额度的免费试用，等它恢复

四类内容各自独立成档，可分别备份与恢复。导出的是 JSON 文件，导入时逐项校验。

上下文（规则说明、策略提示、后果预测、记忆轮数）与规则（决策策略、置信度门槛）。

游戏

      
棋盘与新方块的自然属性。这里改任何东西，都不会影响 Jev 看到的内容，也不影响它怎么决策。

        ~

        加权模式下 2 与 4 的出现比约为 2 : 1（P(2)=2/3）；均匀模式各占一半。
      

    


    

      
      

        开局时随机摆放几个瓷砖。下限不能小于 1 —— 空棋盘上任何方向都动不了，第一步就会判负。
